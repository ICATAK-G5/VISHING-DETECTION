# Desktop service package boundary

This package contains the local FastAPI desktop service, authenticated phone routes, and loopback browser dashboard. Phase 3 supports three independent input paths: Cellular Protection over the existing audio WSS endpoint, consented app-to-desktop WebRTC using aiortc/PyAV with authenticated WSS signaling, and explicitly uploaded voice messages. Each live stream is associated with the paired device, `call_id`, and `near`/`far` role. Live audio is normalized into mono PCM16/16 kHz frames for desktop preview. The RAM preview retains at most 60 seconds per stream. Uploaded voice messages are normalized to WAV and stored under the per-user application data directory for up to 24 hours; users can play or delete them from the loopback-only dashboard. This phase does not add VAD, transcription, or risk scoring. Cellular Protection and Controlled Digital Audio remain distinct modes; neither claims unrestricted cellular-call audio access.
